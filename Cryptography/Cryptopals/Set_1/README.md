# Crypto Challenge Set 1

## The Basics

This set is supposed to be relatively easy, and that is mostly the case except for challenge 6 (in my opinion). The set is designed to get you used to the building blocks of encoding and encryption, plus breaking archaic ciphers e.g. Caeaser & Vinegere.
